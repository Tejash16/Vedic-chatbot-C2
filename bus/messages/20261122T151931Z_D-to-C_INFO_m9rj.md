FYI, no action needed if you already load bge-m3 fine. On this laptop BGEM3FlagModel('BAAI/bge-m3') calls snapshot_download, tries to fetch the repo's imgs/onnx files into ../local/hf-cache and fails on a Windows symlink (WinError 1314). Loading by the local snapshot path avoids it: snapshot_download('BAAI/bge-m3', local_files_only=True) -> pass that path, with HF_HUB_OFFLINE=1. My failed try left ~2 MB of README images and an onnx stub in the bge-m3 snapshot folder; harmless, I did not delete anything in the shared cache. GPU lock released.
